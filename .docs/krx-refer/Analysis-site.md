## 1. 사이트 구조 개요

KRX 데이터 서비스는 2개 도메인으로 분리 운영된다.

| 도메인 | 역할 | 접근 |
|---|---|---|
| `data.krx.co.kr` | KRX Data Marketplace — 통계 조회, 간행물, 데이터 상품 구매 | 로그인 필요(통계), 일부 공개 |
| `openapi.krx.co.kr` | KRX OPEN API — REST API 형태 데이터 제공 | API Key 발급 필요(무료, 관리자 승인) |

## 3. 기본 통계 (통계 > 기본 통계) — 로그인 필요

**접근 방식**: 로그인 후 menuId 기반 JS 네비게이션  
**중요**: 비로그인 시 인증 페이지(MDCCOMS001.cmd)로 리다이렉트

### 3.1 지수 데이터

| 서브메뉴 | 내용 |
|---|---|
| 주가지수 > 전체지수 시세 | KOSPI/KOSDAQ/KRX 시리즈 전체 일별 지수 시세 |
| 주가지수 > 전체지수 등락률 | 등락률/등락폭 |
| 주가지수 > 개별지수 시세 추이 | 특정 지수 시계열 차트 |
| 주가지수 > PER/PBR/배당수익률 | 시장 밸류에이션 지표 |
| 채권지수 > 전체지수 시세 | KRX 채권지수 |
| 파생 및 기타지수 | 파생상품 관련 지수 |

### 3.2 주식 데이터

| 서브메뉴 | 내용 |
|---|---|
| 종목시세 > 전종목 시세 | KOSPI/KOSDAQ 전종목 당일 OHLCV |
| 종목시세 > 전종목 등락률 | 등락률 순위 |
| 종목시세 > 개별종목 시세 추이 | 특정 종목 일별/주별/월별 차트 |
| 종목시세 > 종목 시세 추이(월/연도) | 월봉/연봉 데이터 |
| 종목정보 > 전종목 기본정보 | 종목코드, 종목명, 업종, 상장일 등 |
| 종목정보 > 전종목 지정내역 | 관리/투자주의 등 지정 현황 |
| 종목정보 > 개별종목 종합정보 | 재무정보 포함 종합 |
| 거래실적 > 투자자별 거래실적 | 기관/외국인/개인 매수매도 분류 |
| 거래실적 > 투자자별 순매수상위종목 | 기관/외인 순매수 순위 |
| 거래실적 > 대량매매(전일) | 블록딜 내역 |
| 거래실적 > 프로그램매매 | 프로그램 매매 동향 |
| 기타증권 | REITs, 뮤추얼펀드, BDC 등 |
| PER/PBR/배당수익률(개별종목) | 종목별 밸류에이션 |
| 외국인보유량 추이 | 외국인 지분율 추이 |

### 3.3 증권상품 (ETF/ETN/ELW)

- ETF: 시세, 순자산가치(NAV), LP 호가, 괴리율, 추적오차
- ETN: 시세, 지표가치(IV), LP 호가
- ELW: 시세, 내재변동성, 패리티, 레버리지

### 3.4 채권

- 국채전문유통시장, 일반채권시장, 소액채권시장 구분
- 종목시세, 수익률, 거래실적

### 3.5 파생상품

- 선물: KOSPI200선물, 미니선물, 주식선물, 통화선물, 금리선물, 상품선물
- 옵션: KOSPI200옵션, 미니옵션, 주식옵션
- 세부: 미결제약정, 투자자별 거래실적

### 3.6 일반상품

- 석유(KRX 석유시장), 금(KRX 금시장), 배출권(탄소배출권 시장)

## 10. 트레이딩 플랫폼 개발 관점 시사점

### 10.1 KRX OPEN API 활용 범위

```
백테스팅(F5) ← 무료 OPEN API로 충분
  - 2010년 이후 일별 OHLCV, 투자자별 거래실적
  - KOSPI/KOSDAQ/KONEX 전종목
  - 지수, 파생상품, 채권 포함

기술지표 계산(F2) ← 일별 데이터 기반 (일중 지표 불가)
  - RSI, MACD, Bollinger Bands — 일봉 기준은 가능
  - 분봉/틱 기반 지표 → 브로커 API 필수

실시간 거래(F1, F4) ← 브로커리지 API 필수
  - 호가창(Order Book): KRX 유료 또는 증권사 API
  - 체결장(Tick): 동일
  - 실시간 지수 스트리밍: 증권사 WebSocket
```

### 10.2 데이터 소스 아키텍처 권장안

```
[KRX OPEN API] ──────────── 일별 OHLCV, 종목 기본정보, 지수
                              → 백테스팅 DB, 종목 스크리너

[증권사 WebSocket API] ─────  실시간 체결가, 호가창, 틱 데이터
(KIS, 키움, 대신, 미래에셋)   → ingest 서비스 실시간 스트림

[KRX 투자분석정보] ──────── VWAP, 매수/매도불균형, 모멘텀 지표
                              → 깊이 있는 통계 (로그인 필요)

[뉴스/공시 크롤러] ──────── KIND 공시, 뉴스 API
                              → agents 서비스 감성 분석
```

### 10.3 한계 및 주의사항

1. **실시간 데이터 없음**: KRX OPEN API는 일별 EOD 데이터만 제공. 스캘핑/데이 트레이딩에는 증권사 API 필수.
2. **로그인 필수**: data.krx.co.kr 통계 대부분 로그인 후 접근 가능.
3. **유료 데이터**: 호가장/체결장/일중 데이터는 데이터 구매 필요 (기업용).
4. **API 제한**: OPEN API 이용은 관리자 승인 필요 (수일 소요 가능).
5. **커버리지**: KOSPI/KOSDAQ/KONEX 국내 시장만. 해외(NASDAQ 등)는 별도 데이터 소스 필요.
6. **데이터 시작점**: 2010년 이전 데이터 미제공.
